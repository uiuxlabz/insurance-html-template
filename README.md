# LifeSure — Insurance HTML Template

A premium, framework-free insurance website template built with semantic HTML, CSS custom properties, and vanilla JavaScript. Designed for life, health, and financial protection providers who want a clean, professional web presence.

## Brand

- **Name:** LifeSure
- **Tagline:** Protecting What Matters Most
- **Primary:** Navy `#1E3A5F` / Teal `#0D9488`
- **Fonts:** Raleway (headings) + Open Sans (body)

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, insurance types grid, about preview, testimonials, CTA |
| About | `about.html` | Company story, core values, team members |
| Plans | `plans.html` | 3-tier pricing table with feature comparison |
| Contact | `contact.html` | Quote request form with info cards |

## Features

- Fully responsive (mobile-first breakpoints at 980px and 720px)
- Sticky header with scroll shadow
- Animated reveal on scroll (IntersectionObserver)
- Counter animation for stats
- Burger menu for mobile navigation
- Form validation with success/error feedback
- Back-to-top button
- `prefers-reduced-motion` respected throughout
- Print-friendly styles

## Quick Start

No build step required. Open any HTML file in a browser, or serve locally:

```bash
npx serve .
```
